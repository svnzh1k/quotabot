# Телеграм бот для отслеживания квот на курсы
## Описание
Данный бот позволяет автоматически отслеживать наличие квот на курсы и отправлять уведомления в Telegram.
## Установка и настройка
### 1. Создайте бота в Telegram:
Перейдите к @BotFather, создайте нового бота и получите токен для доступа.

### 2. Получите cookie:
  
Авторизуйтесь на портале и получите cookie, необходимый для взаимодействия с системой.

### 4. Настройте конфигурацию:
Вставьте полученные токен и cookie в файл config.json

### 5. Получите Chat ID:
Напишите вашему боту в Telegram, чтобы он мог определить ваш ChatID. Вставьте этот ChatID в файл "users.txt". Бот пишет сообщения всем пользователям указанным в этом файле

### 6. Настройте отслеживание курсов:
В файле main задайте параметры для отслеживания интересующих вас курсов.

### 7. go run main.go
